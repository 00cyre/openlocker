# System dark mode and clearer Chrome updates

- OpenLocker follows the system light/dark theme automatically. The Chrome popup, lock page, settings, Mac dialogs, blur labels, and installer all adapt without a theme toggle.
- Updating the Mac app installs the matching Chrome extension files and helper in the same transaction. The post-update notice and Mac menu now explain when Chrome still needs Reload.
- The extension detects a newer installed version locally, even offline. A toolbar badge and compact reminder show the installed and running versions. **Open extension settings** opens OpenLocker's Chrome details in a new tab; click **Reload** there and refresh already-open pages when ready.
- Matching versions clear the reminder. Reload checks never change protection lists, unlock anything, or replace your current tab. For multiple Chrome profiles, reload in each profile; the Mac app's receipt reflects the most recently reported version.

Validation: 90 JavaScript tests cover update detection, version comparison, new-tab settings behavior, trusted sender restrictions, notice rendering, and existing lock/update regressions. Swift checks cover the local version receipt and full-install extension payload. Light and dark Chrome layouts were inspected with live media-query changes in a local preview. Release checks build both Mac architectures and exercise installer, recovery, signature continuity, and native messaging behavior. Physical Touch ID and the installed Mac update handoff remain manual acceptance steps.
