# Smooth Chrome tab switches

Fixed a blank flash when switching Chrome tabs. The document guard was hiding every page on focus and visibility changes while waiting for an authorization reply, including ordinary unprotected websites.

Already-authorized pages now stay visible during those checks until their last confirmed deadline. Expired or unknown access still covers immediately. The existing deadline remains armed during a pending check, and denied or failed replies cover the page. A reply that expired in transit cannot briefly reveal protected content.

Five-minute timers remain independent for each app and website. Touch ID behavior, protected lists, tab titles, site icons, and update recovery are unchanged. The Mac app is included at the matching release version with no app-locking behavior changes.

Validation: all 82 JavaScript tests pass, including 100 repeated tab switches each for unprotected and unlocked protected documents, delayed replies, expiry during a pending check, late responses, connection failures, and history restoration. The release workflow also checks the Mac app, installer, update recovery, signature continuity, and native protocol. Visual confirmation in the installed Chrome profile follows extension reload.
