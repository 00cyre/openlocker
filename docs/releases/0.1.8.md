# Cleaner locked-tab titles

Locked-tab titles omit a leading `https://`, `http://`, and `www.` from saved titles and fallback website addresses. For example, `https://www.example.com/notes` becomes `example.com/notes · Locked`. Normal page titles, paths, site icons, and unlock destinations are preserved.

This is a display-only change. Touch ID still waits for deliberate input inside the lock page, and five-minute idle sessions and update recovery are unchanged.

Validation: lock-page regression tests and manifest/script checks, plus the release workflow's extension, Mac, installer, signature continuity, and native-protocol checks.
