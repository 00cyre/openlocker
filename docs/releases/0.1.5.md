# Five minutes of breathing room

- Unlock a site or Mac app once, then switch tabs, windows, and apps freely. Hiding or minimizing a Mac app preserves its unlock too.
- Everything you previously unlocked relocks after **five minutes without keyboard or mouse input anywhere on your Mac**. Each new input restarts the idle timer; returning after the timeout requires Touch ID again.
- Website unlocks cover the authenticated domain and its subdomains across Chrome tabs and windows. Other protected domains still require their own Touch ID confirmation.
- **Lock all now**, Mac screen locking/sleep, and component restarts still revoke grants. Restarting a protected Mac app starts a new process and requires authentication again.
- An idle lock page waits until you return before opening Touch ID automatically. Old authentication responses cannot reopen a session that expired while the prompt was pending.
- Updated the interface, documentation, and HyperFrames walkthrough to explain the new behavior. Uses the existing permissions and persistent signing identity.

Validation: extension tests cover the exact five-minute boundary, repeated input resets, tab/window switching, domain scope, worker recovery, localhost navigation, cancellation, and stale authentication. Mac policy tests cover the same idle boundary and grant invalidation. Universal builds, installer upgrades, signing continuity, native messaging, and the demo are checked before publication. Physical fingerprint and five-minute real-Mac acceptance checks remain listed in `docs/TESTING.md`.
