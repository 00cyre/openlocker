**Superseded by 0.1.4.** This release attempted to fix the repeated Touch ID prompt after successful website authentication, but local verification showed that the loop remained.

Chromium treats an empty resource exclusion list as the same default that excludes the main page. The original regression test missed that distinction. Version 0.1.4 explicitly lists resource types, including the main page, and corrects the test using Chromium's implementation as the reference.

Use **Check for updates** in the extension to install the corrected release when available.
