Corrects the website unlock loop left unresolved by 0.1.3.

Temporary allow rules now explicitly list resource types, including `main_frame`. Chromium's implementation treats both omitted filters and empty exclusion lists as its default, which excludes the main page. That caused a successful fingerprint check to redirect immediately back to the lock screen and prompt again.

The regression test now follows Chromium's actual resource-mask behavior. It verifies that an authenticated localhost navigation reaches the page, page resources remain usable, other tabs remain locked, and Lock all revokes access. All 34 extension tests pass. Physical Touch ID and the loaded Chrome extension still need local verification.

Use **Check for updates** in the extension to download and activate this release. The Mac app includes the corrected extension for Chrome setup. Existing protected domains/apps are retained, and the Mac signing identity is unchanged.
